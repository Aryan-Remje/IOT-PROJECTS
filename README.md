## Introduction

**IOT-MICRO-PROJECT** is a collection of small Internet-of-Things builds: microcontrollers that read sensors, communicate over the network, and do something useful with the data.

Each project is kept intentionally small so it's easy to build, understand, and extend.

---

## Contents

All project source code, the required files for each project, and their documentation are included in this repository. Every project lives in its own folder with a short guide covering wiring, setup, and usage.

---

## Project Structure

```text
IOT-MICRO-PROJECT/
├── projects/      # Individual IoT projects, each with its own code and docs
├── lib/           # Shared drivers and helper code
└── README.md
```

---

## Quick Start

```bash
git clone https://github.com/<your-username>/IOT-MICRO-PROJECT.git
cd IOT-MICRO-PROJECT/projects/<project-name>
```

Open the project's folder in Arduino IDE or PlatformIO, follow the documentation inside it, and flash the board.
